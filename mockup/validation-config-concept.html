Решения, зашитые в концепт — обсудим при утверждении

  1. Кнопка «Проверить все» уходит. Вместо неё — чекбокс «выбрать все» в шапке таблицы (выбирает всё по текущему фильтру) + кнопка «Проверить выбранные», активная при выборе.
  2. Промт всегда предзаполнен стандартным (текущий SYSTEM_PROMPT GLM). Кнопка «Вернуть стандартный» появляется только после правок. Между запусками промт не сохраняется — каждый запуск начинается со стандартного.
  3. Шаблон — радио-карточки. Сейчас один (по умолчанию, отмечен), место под будущие зарезервировано и не мешает. Выбор шаблона уже сейчас передаётся в бэкенд — задел на несколько шаблонов.
  4. Тот же диалог — для одиночной проверки. Кнопка «Проверить» в строке документа открывает этот же диалог с N=1 (быстро: выбрать → запуск). Альтернатива — одиночную оставить мгновенной без диалога, скажите, если так удобнее.
  5. Выбор и пагинация. Выделение живёт до смены фильтра или страницы; при бесконечной догрузке новые строки приходят неотмеченными, «выбрать все» отмечает все загруженные по фильтру.
  6. Прогресс — существующая полоса «Проверка k из N…», статусы в строках переключаются на «проверяется».
